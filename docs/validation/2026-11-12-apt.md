# APT-only application installation — 2026-11-12

The active `config`, the hardware validation configuration in
`.cache/config-hardware`, and `config.example` now select
`LILYGO_UI_INSTALL=apt` with `https://lilygo-ui.github.io/packages`.
The default application set is the 26 packages in `stage3/packages`:
AppKit, Launcher and 24 applications. Explicit package-list overrides remain
available for deliberately smaller images.

The Docker wrapper no longer mounts local DEB directories. Both build entry
points reject `LILYGO_UI_INSTALL=local`, and stage3 has no local DEB installer
or fallback. The image retains the `stable/main` riscv64 APT source and its
dedicated signing key for subsequent package updates.

The public key is stored in `keys/lilygo-ui-archive-keyring.gpg`, with
fingerprint `FAC75BB28CE621CB6D5353A1C309120B7DC98F4A`. Its source and file hash
are recorded in `keys/README.md`. Preflight verifies InRelease, the signed
index hashes and package architecture/version availability before creating a
rootfs. APT still performs dependency resolution and artifact verification at
installation time. Image provenance records the repository URL, requested
packages and public-key hash; the package manifest records installed versions.
