# LILYGO UI 镜像验证 — 2026-11-07

这版镜像从空 Debian rootfs 完整构建，安装独立发布的 UI 包并通过导出检查。
开机配置为 Launcher 图形首次设置：地区 → 创建用户名/密码 → 网络 → 更新 → 完成。
网络和更新可跳过，没有固定默认账号或密码。

## 适配内容

- `LILYGO_UI_PLATFORM=k230` 选择显示/输入/软件渲染；
  `LILYGO_UI_TARGET_OS=debian` 选择 Debian 包、systemd、PAM 和账号管理。
- Launcher 亮度与音量调用共享 `LilyGoUI::Hardware`。AppKit 保留原生 ALSA
  自动发现、分离左右声道及 dB 映射；源码 SDK 显式依赖 ALSA 开发包。
- Debian 地区配置使用通用 helper；CM0 原有 raspi-config 后端保留。
- systemd 输入设备自动发现，默认竖屏，不等待联网才启动向导。
- 创建账号前写入不含密码的恢复日志，处理创建中断；账号提交后仍需 PAM 验证。
- 镜像采用 `ACCOUNT_SETUP=launcher`，不创建普通用户，root 锁定，SSH 关闭。
  向导创建的用户具有密码认证 sudo 及已配置的设备访问组。

## 实机边界与使用

尚未将这版新镜像烧录到目标板验证。实际屏幕、触摸、音频、Wi-Fi及应用切换仍需
上板验收；容器和QEMU测试不等同于真实K230图形硬件测试。

烧录本版镜像后由屏幕向导创建账号和密码，创建后可用相同凭据登录串口并执行sudo。
SSH默认关闭；需要时可在登录后的终端运行 `sudo systemctl enable --now ssh`。
此版本没有预装全部LILYGO应用，也未迁移camera/ISP等专有用户态服务。
